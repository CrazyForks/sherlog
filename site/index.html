sherlog

The local memory layer for coding agents.
Search Codex, Claude Code, and Pi session history from your terminal — no cloud, no embeddings, no docs tax. 给 Coding Agent 用的本地记忆层。
在终端里极速搜索 Codex、Claude Code 和 Pi 的历史对话——不上云、不用向量库、不用写文档。

Latest native release: v0.5.1. macOS arm64/x64 · Linux x64 GNU. No Node.js, no build from source, no sudo. 最新原生版本：v0.5.1。macOS arm64/x64 · Linux x64 GNU。无需 Node.js，无需从源码编译，无需 sudo。

Upgrading from 0.4.x? Run shlog sync once. The legacy index migrates to the native format automatically: a .v7.bak backup is kept, coverage is rebuilt for the synced scope, and the old 0.4.4 writer no longer touches the index. Content commands point at this migration with a typed index_schema_upgrade_required nextAction. 从 0.4.x 升级？跑一次 shlog sync 即可。旧索引会自动迁移为原生格式：保留 .v7.bak 备份、同步范围内 coverage 重建、旧 0.4.4 writer 不再写入。内容命令会以 typed index_schema_upgrade_required + nextAction 指路这次迁移。

Quick Start 快速开始

Build the index once, find the session that matters, then read the surrounding dialogue. 先建一次索引，找到关键会话，再阅读上下文对话。 

# 1. Build the local index once
shlog sync

# 2. Find the session that matters
shlog find "JWT server sessions" --json

# 3. Read the surrounding context
shlog read-range <sessionRef> --seq 18

Why not Embeddings? 为什么不用 Embedding？

Because agents are already the semantic engine. Embeddings try to do semantic thinking for humans, but an Agent is a world-class reasoner. Chunking logs into a vector database destroys the causal timeline (Command → Error → Fix). Sherlog uses fast full-text search to drop a bookmark in the timeline, then lets the Agent read the surrounding conversation itself. 因为 Agent 本身就是最强的语义引擎。Embedding 试图替人类做语义理解，但 Agent 本来就是顶级推理器。把对话切碎塞进向量库，会破坏“执行命令 → 报错 → 修复”的因果时间线。Sherlog 用极速全文检索在时间线上放下锚点，把上下文阅读交还给 Agent。

Why not ripgrep? 为什么不用 ripgrep？

rg finds raw JSONL lines. Agents need conversational context, not unparsed strings. Sherlog understands session structure: it finds the exact message, then provides read-range and read-page for the Agent to page through the dialogue cleanly. rg 只能翻出杂乱的原生 JSONL 行；Agent 需要的是对话上下文。Sherlog 真正理解会话结构：先精确定位消息，再用 read-range / read-page 让 Agent 干净地翻阅上下文。

Zero Documentation Tax 零文档整理负担

Your raw agent history is already the best runbook. Don’t stop to write clean notes. The conversation where you and your agent solved a problem last time is directly searchable next time. 你和 Agent 的历史对话，就是最好的 Runbook。不用停下来整理文档。上次怎么解决问题的，下次直接搜得到。

A Composable Primitive 高度可组合的基础组件

Sherlog is a retrieval primitive, not a walled garden. It outputs standard JSON. Pipe it to jq, read the raw file, or hand the context to other tools like Mainline. Sherlog 是底层检索组件，不是封闭生态。它输出标准 JSON，可以接 jq、直接读原文，也可以把上下文交给 Mainline 等其它工具。
